# AvatarCam
## Virtual camera to convert people into avatar.

## Requirements
- Unreal 5.1.1.
- Visual Studio 2019 community.

## Notes
- Do not track large binary files except *.uasset and *.umap.
- Use .gitattributes to track large files with Git LFS.
- Need to copy Binaries/, Libs/, Plugins/ and ThirdParty/ manually.
